# 🏠 REAL-ESTATE-PROPERTY-LISTING

A console-based Real Estate Property Listing System built in C language.

## 📌 About The Project
This project is designed to manage real estate properties efficiently. It allows users to add, view, search, and manage property listings with details like property ID, type, price, location, and owner details.

Ideal for academic projects and for understanding File Handling and Structures in C.

## ✨ Features
- ➕ Add New Property
- 📋 View All Properties
- 🔍 Search Property by ID / Location / Price
- ✏️ Update Property Details
- ❌ Delete Property
- 💾 File Handling - Data stored permanently
- 🧱 Structured using `struct` in C

## 🛠️ Built With
- Language: C
- Concepts: Structures, File Handling, Functions, Loops
- Platform: Nimbus / VS Code / Any C Compiler
